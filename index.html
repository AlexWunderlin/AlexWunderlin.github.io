Parks Maintenance
Brown County Parks
June 2024 - August 2026

As a parks employee, I was responsible for maintaining park landscape and facilities. Working with my team to ensure we stayed on top of our large list of responsibilities was a large part of the job. Every day came with new tasks which meant that a lot of the job was also about learning and adapting to new challenges. One of my larger accomplishments during my time with the parks was the repair and customization of a firewood vending machine. It started with a broken button that was used to unlock the doors so the machine could be restocked. The button's original location was difficult to access though so I recommended replacing it with a key switch and planting it on the front of the machine so that it would be more accessible. Later they wanted to update the price per bundle from five to six dollars. I found that the bill reader was set up to allow various prices using dip switches, but it still couldn't be set to six dollars without reprogramming the PLC which explained why they were having trouble setting the price normally. Based on my knowledge of how the bill reader sent pulses to the PLC, I anticipated that within the code there was a counter value set to 20 and that it could be changed to set the price. After finding the correct programming cable, I was able to confirm my suspicions and update the program but was unable to upload it with the free version of the software used to interact with the PLC. Due to concerns of cost, I instead wrote up documentation describing the process of modifying the price so that others would be able to do it should they decide to get the software in the future.
